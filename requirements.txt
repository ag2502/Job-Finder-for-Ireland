# Runtime dependencies for the Vercel deployment of the web finder.
#
# This is deliberately NOT the full `[project] dependencies` from pyproject.toml. That
# list also covers the crawler, which runs in GitHub Actions and shares nothing with this
# function but the package it imports from. A serverless bundle has a hard size ceiling,
# and every crawler-only wheel shipped here spends it for nothing.
#
# What was dropped and why, each verified to leave `api/index.py` importable:
#   psycopg[binary] - the heaviest wheel here, and since the site serves the read-only
#                     SQLite snapshot it has no database driver to load at all.
#   alembic         - migrations are a crawler concern; the snapshot ships its schema.
#   uvicorn         - Vercel supplies the ASGI server.
#   selectolax      - HTML-to-text runs at ingest, in the pipeline, not at read time.
#
# pypdf and python-docx stay: they are imported lazily, but by this function, when
# someone uploads a CV.
#
# httpx was on that dropped list until accounts arrived. It is back because the function
# now does make requests: sign-in and application history go to Supabase over its REST
# API. It is the cheapest way to do that - a couple of megabytes - and the reason
# Supabase was chosen over an SDK-first service, whose client would have brought grpc
# and protobuf into a bundle that is kept deliberately small.
